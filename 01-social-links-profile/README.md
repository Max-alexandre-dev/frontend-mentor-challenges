# Social Links Profile

**Do Design ao Código — Desafio #01**

Minha solução para o desafio [Social Links Profile](https://www.frontendmentor.io/challenges/social-links-profile-UG32l9m6dQ), da plataforma Frontend Mentor.

O objetivo foi recriar uma interface de perfil com links para redes sociais, praticando estruturação de páginas, estilização e responsividade.

## Preview

![Resultado do Social Links Profile](./screenshot.png)

## Tecnologias utilizadas

- HTML5
- Tailwind CSS
- Vite

## Funcionalidades

- Exibição de foto, nome, localização e descrição.
- Links para redes sociais.
- Layout responsivo.
- Estilização dos componentes utilizando Tailwind CSS.

## Como executar

**Pré-requisito:** Node.js instalado.

Clone o repositório:

```bash
git clone https://github.com/Max-alexandre-dev/frontend-mentor-challenges.git
```

Acesse a pasta do desafio:

```bash
cd frontend-mentor-challenges/01-social-links-profile
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Abra o endereço informado pelo Vite.

## O que pratiquei

Neste desafio trabalhei com estruturação HTML, classes utilitárias do Tailwind CSS, alinhamento, espaçamento e adaptação de layouts.

A proposta da série é continuar evoluindo e compartilhando o processo de construção de cada interface.
